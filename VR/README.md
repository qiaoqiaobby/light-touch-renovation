# VR 离线全景（单文件 WebGL 全景查看器）

本目录包含一个自包含的 HTML 文件 `VR离线全景.html`，内含 14 个场景、84 张全景贴图。文件在浏览器中以 WebGL cubemap 方式渲染全景，支持拖动转向、滚轮缩放与场景切换。文件不依赖网络、服务器或任何外部资源，通过 `file://` 直接打开即可运行。

本文档面向程序化解析与自动化处理：说明文件的物理结构、内嵌数据契约、渲染管线参数，以及哪些字段实际生效。人工查看只需双击 HTML 文件，无需阅读本文档。

## 内嵌数据契约

第 44 行内容为单个 JSON 对象。以下为完整结构，字段名与取值原样保留。

```json
{
  "title": "VR 离线全景",
  "scenes": [
    {
      "i": 0,
      "room": "客厅",
      "adj": [1, 2, 4, 5],
      "faces": ["data:image/avif;base64,<base64>", "...共 6 项"]
    }
  ]
}
```

### 顶层字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `title` | string | 固定值 `"VR 离线全景"`。渲染脚本未读取该字段 |
| `scenes` | array | 场景列表，长度 14，顺序即界面切换顺序 |

### `scenes[]` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `i` | number | 场景序号，取值 0–13 且与数组下标一致。渲染脚本未读取该字段 |
| `room` | string | 房间名，用于界面标签与 HUD 显示 |
| `adj` | number[] | 相邻场景的 `i` 值，表示空间连通关系。渲染脚本未读取该字段 |
| `faces` | string[6] | 6 张立方体贴图的 data URI |

### `faces` 数组顺序

`faces` 的下标与 GL 立方体贴图面固定对应。该顺序由渲染脚本的 `TARGETS` 常量确定，不可重排。

| 下标 | 语义面 | GL 枚举 |
| --- | --- | --- |
| 0 | right | `TEXTURE_CUBE_MAP_POSITIVE_X` |
| 1 | left | `TEXTURE_CUBE_MAP_NEGATIVE_X` |
| 2 | up | `TEXTURE_CUBE_MAP_POSITIVE_Y` |
| 3 | down | `TEXTURE_CUBE_MAP_NEGATIVE_Y` |
| 4 | front | `TEXTURE_CUBE_MAP_POSITIVE_Z` |
| 5 | back | `TEXTURE_CUBE_MAP_NEGATIVE_Z` |

每项为完整 data URI，前缀固定为 `data:image/avif;base64,`。

## 渲染管线

第 45–275 行的脚本按以下方式工作。

### 着色器

顶点着色器将全屏三角带直接映射到裁剪空间。片元着色器按相机基向量构造光线方向并采样立方体贴图：

```glsl
vec3 d = normalize(uFwd + uRight*(vNdc.x*uTanHalf*uAspect) + uUp*(vNdc.y*uTanHalf));
gl_FragColor = vec4(textureCube(uCube, vec3(-d.x, d.y, d.z)).rgb, 1.0);
```

采样方向的 X 分量取负。注释说明这与原始查看器的 three.js 行为一致，若去除该负号，全景会左右镜像。

### Uniform 变量

| 名称 | 类型 | 含义 |
| --- | --- | --- |
| `uCube` | `samplerCube` | 立方体贴图，绑定纹理单元 0 |
| `uRight` | `vec3` | 相机右向量 |
| `uUp` | `vec3` | 相机上向量 |
| `uFwd` | `vec3` | 相机前向量 |
| `uTanHalf` | `float` | 垂直视场角半角正切值 |
| `uAspect` | `float` | 画布宽高比 |

### 相机与视场

| 项 | 值 |
| --- | --- |
| 初始方位角 | `atan2(0.2126284749124021, 0.9770480010705863)` |
| 初始俯仰角 | `asin(-0.012897102790853581)` |
| 初始视场角 | 95° |
| 视场角范围 | 30°–120° |
| 滚轮步进 | 每次乘以 `1 ± 0.08` |
| 俯仰角钳制 | ±1.5 弧度 |
| 设备像素比上限 | 2 |

相机基向量按 `right = cross(fwd, [0,1,0])`、`up = cross(right, fwd)` 计算。

### 贴图加载

切换场景时，脚本为当前场景的 6 张 `faces` 各创建一个 `Image`，在 `onload` 中通过 `texImage2D` 上传到立方体贴图。场景切换期间旧纹理被覆盖。同一时刻只有当前场景的 6 张纹理驻留。

## 错误处理与兼容性

| 情况 | 实际行为 |
| --- | --- |
| 无法创建 WebGL 上下文 | 显示错误面板，提示使用支持 WebGL 的浏览器 |
| 着色器编译或链接失败 | 显示错误面板，提示着色器编译失败 |
| 单张贴图加载失败 | 触发 `onerror`，仍然递减计数器；6 张全部结束后照常标记就绪并绘制 |
| 浏览器不支持 AVIF 解码 | 走上一行的失败路径，界面不报错，绘制结果为空或残留前一场景纹理 |

运行该文件要求浏览器同时具备 WebGL 与 AVIF 解码能力。未在 Chrome 之外的浏览器上验证。

## 程序化处理建议

### 提取数据

```text
1. 定位 `<script id="sceneData" type="application/json">` 与紧随其后的 `</script>`。
2. 取两者之间的文本，作为 JSON 解析。
3. faces 中的 data URI 可按首个逗号分割，右侧为 base64 载荷。
```

避免整文件读入内存后再正则匹配，base64 载荷占 99.9% 的体量。

### 提取贴图

```text
1. 解析 JSON 得到 scenes。
2. 对每个场景，按 faces 下标顺序解码 6 张 AVIF。
3. 按 GL 面枚举上传，即可还原该场景的立方体贴图。
```

### 校验要点

- `scenes` 长度为 14，每个 `faces` 长度为 6。
- `faces` 每项以 `data:image/avif;base64,` 开头。
- `i` 与数组下标一致。
- 每个 `adj` 中的值均为有效的场景下标，且关系对称。

## 生成背景

该文件由脚本从某一在线全景查看器的资源生成，贴图来源为公开 CDN。按需求，原查看器的来源链接、工程标识与房源名称已从本文件中移除，文件中不含任何外部 URL。

面与轴的对应顺序由测量确定：读取运行中查看器的立方体贴图对象，将 6 个纹理槽位的像素与本地文件比对，匹配度在 0.97 以上。

# light-touch-renovation

住宅微改。一间三室，六套客厅答案，两把尺子。

```
┌────────────────────────────────────────────┐
│  LIGHT TOUCH            上北下南            │
│  客厅主体   3364 × 5738 mm                  │
│  标注面积   29.7 ㎡        复算  29.83 ㎡    │
│  单尺误差   ±15 mm         层高  2.70 m 假定 │
└────────────────────────────────────────────┘
```

新业主独居，以后可能有伴侣，节假日父母来住。客厅要影视、投屏、阅读、运动、待客。审美是简约、日式侘寂。电视可以不要，冰箱可以挪，旧餐桌丢掉，换一张平时坐两人、展开坐一桌人的折叠桌。预算和打算住几年还没定。

上一任住户 2026-09 拍的全景在 `VR/`。画面里的沙发、餐桌、中国结都不是新业主的，诊断时只认地面、墙、门窗、固定柜和插座。

## 看

给客户的只有一个文件：住宅微改提案 `docs/plan/住宅微改提案-202610170831.html`（取最新的时间戳）。用电脑浏览器双击打开，不用联网。手机上的文件预览不运行脚本，只会看到一段提示。

它按客户做决定的顺序编章：需求、现状、先盲选拼贴、客厅三种摆法、四套风格（三维 L0–L3、拼贴与平面联动）、并排比较、实施阶梯、还没定的事。客户的选择存在本机浏览器里，第 8 章整理成一段文字，方便发回。拼贴是第三方返图，这个文件只给业主本人，不部署成网址。

减沿用原来的轴线，65 寸幕布，坐面前沿到幕布 2372 mm。分用书架把客厅切成三段，西侧通道 964 mm，沙发到吊装幕布 1560 mm。空把中段留给席地和运动，墙面投影约 55 寸，矮榻前沿到墙 2430 mm。这四个数由 `src/floorplan/scheme-metrics.ts` 从摆放数据现算，交付页按「大于 1 m 换算成米」写成 2.4 m、964 mm、1.6 m、2.4 m。

设计方的内部工作稿，不直接发给客户：

- 户型三维：`npm run dev:plan`，打开 http://127.0.0.1:5173/ 。能开关门、剖切墙、看示意家具。
- 全屋三维装修页 `docs/plan/全屋三维装修-*.html` 和拼贴板 `docs/plan/全屋风格方案-*.html`，内容已经并进交付页。
- `viz/` 的两张离线方案页已经归档。它们是户型图按 14 mm/px 推出来的旧壳，上面的 90 寸、1.8 m 通道、80 寸投影都不成立。墙、台、动只在那里，交付页附录只写了定性描述。

## 改

| 要动什么 | 改这里 | 然后 |
| --- | --- | --- |
| 墙、门、房间面积 | `src/floorplan/plan-data.ts` | `npm run audit:plan` |
| 减 / 分 / 空怎么摆 | `src/floorplan/living-schemes.ts` | `npm run audit:plan` |
| 四套风格的色板、拼贴、卧室和厨卫摆放 | `boards/data/schemes.mjs`、`boards/data/house.mjs` | `npm run board:check` |
| 交付页的文字、版式、章节 | `src/present/`（先读 `DESIGN.md` 第 10 节） | `npm run present:build`，再 `npm run present:shots -- <产物路径>` |
| 归档页的家具 | `viz/src/schemes.js`，创意页在 `viz/src/creative/schemes.js` | `npm run validate` |

`audit:plan` 先核对六间面积和门洞，再跑三个方案各五种状态：人要能从入户走到厨房、卫生间和北侧过道，聚会不少于 6 座，运动区里要有一块 2000 × 1000 的空地。在东墙外多放一块，检查会失败。这是故意的。

从 `viz/src/schemes.js` 把坐标抄进三维，靠东墙的沙发会穿出去。两套尺子差在哪，写在 `docs/plan/客厅三方案并入复尺-对抗审查-202610120646.md`。

方案按 `promept.md` 推：先需求，再保留，再诊断，再从能撤走的改动往上加。拆墙、开洞、移动水电只写成需要专业人员评估的选项。

`npm run check` 一次跑完户型、风格、装修三套审查、类型检查和交付页规范检查。`present:build` 会先跑这些，任何一项失败都不出页面。

`VR/` 只读。进度看 `ROADMAP.md`。

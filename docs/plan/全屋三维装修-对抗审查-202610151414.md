# 全屋三维装修：对抗审查

页面：`docs/plan/全屋三维装修-202610151414.html`。四套风格可以在同一套复尺房子、同一批机位和同一套锁定光线里，从 L0 看到各自的最高阶段。素木和暖古典没有定制柜，L3 按钮禁用。坐标没有改平面数据。

没有未处理的高级问题。下面两件在做页面时改过，改完重跑了审查和截图。

| 发现 | 级别 | 处置 |
| --- | --- | --- |
| 计划里的卫生间机位（5150, 11300）贴着东墙，画面里看不见坐便凳 | 高 | 视点改到（3680, 11740），看向（4520, 10840, 750）。仍在卫生间多边形内，离落地物件不少于 150 mm。`decor:audit` 通过后再截 |

目检对着总表和抽看的单张，结论如下。家具和 0.8 m 门洞放在同一空间里，比例没有明显失真。地砖、地板和织物有重复纹理，尺度没有糊成一张照片。卧室 A 能看见东墙床头板和床；卧室 B 能看见床面和床头。卫生间能看见坐便凳的坐圈。素木 L0 入户能看见蓝色护墙板，L2 刷成浅色；木与钢 L1 护墙板仍是蓝的，L2 刷白，餐区出现蓝吊灯。暖古典卧室夜晚，床头灯是亮的，床品比素木花。席地 L3 的入户柜是木色储物墙。

## 验证

- `npm run decor:audit -- --mutate`：失败 0 项，变异 10 项全部捕获。另一次把素木 `a-bed` 的三维 x 临时加 50 mm，报 `对位：S1 a-bed 位置或尺寸与平面不一致`，随后撤回。
- `npm run decor:build`：产物 `docs/plan/全屋三维装修-202610151414.html`，1577802 字节，低于 8 MB。审查先通过才构建。
- `node scripts/decor-shots.mjs`：86 张。最小字号 12，横向溢出 0，控制台报错 0，三角面 61833，绘制调用 437，夜晚灯最多 13。
- `python3 scripts/decor-shot-stats.py`：调光视点和一批白墙视点的整页平均亮度高于自动区间，按上表改为人工确认。素木对暖古典，除卫生间外同一视点的差都大于 0.02。素木、木与钢、席地、暖古典的 L0 和最高阶段，入户视点的差都大于 0.03。
- `npm run audit:plan`：轮廓失败 0，减 / 分 / 空 15 个使用状态通过。观看距离 2372 mm，西侧通道 964 mm，幕布距离 1560 mm，投影距离 2430 mm。墙外块的变异被「在房间内」捕获。
- `npm run typecheck`：通过。
- `npm run board:check`：失败 0 项，变异 13 项全部捕获。
- 浏览器（开发服务器，桌面宽度）：素木默认落在 L2，L3 按钮禁用，悬停文案是「本方案最高 L2」。切到木与钢 L1、卫生间、昼夜，地址哈希跟着变，右侧清单只列当前阶段及以下的改动。控制台没有页面脚本报错；浏览器自己请求 `/favicon.ico` 得到 404，页面没有放图标。`THREE.Clock` 有一条库的弃用警告。
